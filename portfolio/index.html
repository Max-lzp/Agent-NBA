02 / PRODUCT THINKING

从用户问题，到 AI 能力边界。

01

信息按观看目的组织

老球迷关注数据与对位，新观众需要术语解释，陪伴观看需要话题引导。三种模式探索同一内容的不同表达。

待验证：增强信息是否提升理解，是否干扰观看。

02

回答有来源，缺失不编造

分析师通过工具查询事件清单、官方逐回合和赛季统计；校验人名与数字，不让模型凭画面编造比赛事件。

评测重点：事实准确性、来源支撑、缺失值处理。

03

基础回放优先

为分析师冷启动或调用异常设计事件清单兜底，减少增强能力失败对基础回放的影响。

完整云端链路需在恢复服务后重新验收。

03 / SYSTEM DESIGN

技术选择服务于观看体验。

  1. 视频理解

    YOLO + ByteTrack
    Qwen3-VL · Rekognition · OCR

    目标追踪、球衣号码和身份辅助识别
  2. 数据与分析

    Python · Claude Sonnet 4.6
    Bedrock Converse · AgentCore

    关联官方数据，通过工具调用生成解释
  3. 任务编排

    S3 · Lambda · DynamoDB
    EventBridge · Step Functions · Batch

    上传、处理、任务状态及异常兜底
  4. 回放交付

    FFmpeg · JavaScript
    CloudFront · TypeScript / AWS CDK

    视频合成、网页交互和基础设施定义
