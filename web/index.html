技术架构

录像不进应用服务器。浏览器经 CloudFront 进来，直传到 S3；分析编排在 AgentCore，事件写入 DynamoDB，回放页再按任务号取回。

  1. 01 打开 CloudFront 发网页。/api 转到 API Gateway。
  2. 02 入库 Lambda 建任务，浏览器用预签名地址把视频放进 S3。
  3. 03 理解 AgentCore 调 Bedrock：画面用 Qwen3-VL，事件用 Claude。
  4. 04 成片 Batch 做 GPU 跟踪，Textract 读记分牌，MediaConvert 合成。
  5. 05 回放 DynamoDB 里的事件画到时间线。Polly 出两句解说。
