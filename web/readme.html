Deep Court

让每一次出手被重新讲述一遍。把比赛录像变成可交互的深度回放：事件落在时间线上，数据长在画面上。

作品亮点

  1. 回放页按时间码列出出手、篮板、失误等事件。点某一条，画面和数据一起跳到那个回合。
  2. 暂停时展开防守压力等深度数据。默认画面自己能看懂，展开层是越看越有，不是不点就不懂。
  3. 视频经 S3 预签名直传，不经过应用服务器。上传完成后自动分析，状态从等待、分析中到完成或失败。
  4. 分析跑在 Amazon Bedrock AgentCore。有画面时用 Qwen3 VL 看帧，否则用 Claude Sonnet 写结构化事件；一个模型失败就换另一个。
  5. 任务和事件分表存在 DynamoDB。页面通过 CloudFront 同源调用 API Gateway，背后是四支 Lambda：建任务、分析、读状态、读事件。
  6. 整套资源用 AWS CDK 定义，角色挂参赛权限边界，权限收到各自的表和 S3 前缀。

这条链路怎么走

浏览器打开站点 → POST /api/jobs 建任务并拿到上传地址 → 视频进 S3 raw/ → Lambda 调 AgentCore → 事件写入 DynamoDB → game.html?jobId= 轮询并画出时间线。
