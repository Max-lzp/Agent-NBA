# NBA 官方事件录像下载：方法与教训（2026-10-10）

目标：把 `shotqualityshotlog` 里每球附带的 mp4（videos.nba.com 官方回放）批量下到
`data/2025-26/clips/{gameId}_{eventNum}.mp4`，用官方节次/比赛钟/投篮人做标准答案。

## 最终固定方法（可直接复用）

```bash
python3 scripts/fetch_clips.py            # 四场「最后 60 秒」投篮（已抓完，64 个）
python3 scripts/fetch_clips.py --per-game 50   # 每场前 50 个（号码识别素材）
python3 scripts/fetch_clips.py --all      # 四场全部约 693 个
```

脚本核心：请求必须带**全套 Chrome 视频元素请求头**（`scripts/fetch_clips.py` 顶部
`HEADERS` 常量，11 个头一个不能少），下载后 ffprobe 校验时长与官方 `largeDuration`
一致（容差 0.6s）才算成功，否则自动重下。断点续跑：已校验文件直接跳过。

## 尝试与失败记录（按时间顺序）

### 1. 「本机访问 videos.nba.com 会 403」——过时结论
README 里的旧结论。复测：curl 默认 UA、python urllib、浏览器 UA 全部 HTTP 200。
**教训：网络封锁类结论要当场复测，别沿用几周前的记忆。**

### 2. 裸请求拿到 200 + 真 URL + 错误内容（最大坑）
四场 65 个「最后 60 秒」URL 直接下载全部「成功」（200，~31MB/个）。
抽查发现：不同 event 的文件**字节完全相同**（md5 一致），内容是一段 15 秒的
「VIDEO NOT AVAILABLE」占位视频（1280x720，31,580,089 字节，XMP 元数据是
MGM 夏季联赛模板）。连 `.jpg` 缩略图、`.vtt` 字幕 URL 都返回同一份占位 mp4。
**教训：HTTP 200 + 正确 URL ≠ 拿到真内容。批量下载必须抽样校验内容
（时长对官方记录 / 哈希互比），否则会在垃圾数据上白跑下游全部流程。**

### 3. 排查占位原因时的错误假设（全部排除）
- ❌ CDN 缓存串台：FetchURL（另一网络出口）也拿到同一份占位 → 不是本机问题。
- ❌ 链接过期：nba.com 官网 stats/events 页（bitmovin 播放器）能正常播放同一
  URL 的真实画面 → 链接有效。
- ❌ 少几个请求头就行：单加 Range / Referer / Sec-Fetch-Dest 都不够。
- ❌ TLS 指纹（JA3）：curl_cffi 模拟 Chrome120 指纹拿到的仍是占位。
**教训：Akamai 对非浏览器流量做的是「软拦截」——不回 403，回 200 + 占位内容。**

### 4. 成功：全套 Chrome 视频元素请求头
在 InAppBrowser 里抓到官网播放器的真实请求（206），逐一复刻完整请求头后
curl 拿到真实内容（12 秒 8.6MB，时长与官方记录精确一致）。二分试验证明
不能缺任何一个头。Referer 用 `https://www.nba.com/game/{gameId}/play-by-play`
即可，不需要与事件对应的精确页面。

## 数据事实（供下游使用）
- 真实 1280x720 约 5.7Mbps：12 秒 ≈ 8.6MB（65 个共 0.54 GB；全量 693 个约 6 GB）。
- 占位视频指纹：31,580,089 字节 / 15.015s，可用于快速识别垃圾文件。
- 清单文件：`data/2025-26/clips/_manifest_<模式>.json`，每条含
  gameId / eventNum / period / gameClock / playerId / playerName / eventType /
  durationMs / url / 落盘文件 / 校验时长。文件名即 `{gameId}_{eventNum}.mp4`，
  可直接 join 官方记录。
- `gameClock` 格式为 `M:SS`（分钟不补零，如 `0:46`）；筛「小于 1:00」按分钟==0。
- **录像是 60fps**（不是 29.97）：抽帧/运动估计按 60fps 算，别按转播常规帧率。
- 四场最后 60 秒投篮实际 64 个（0022500160×15、0022500356×12、0022500491×15、
  0022500701×22），全部通过时长校验 + 抽帧人工核对（记分牌节次/比分与官方一致）。

## 备用路线（请求头失效时）
InAppBrowser 打开 `https://www.nba.com/stats/events?GameEventID=<eventNum>&GameID=<gid>&Season=2025-26&flag=1`
播放器能出真实画面；可以截图/逐帧截取拿画面（canvas 受跨域污染限制，截图不受限）。
适合少量补数，不适合批量。
