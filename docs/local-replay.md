# 第一阶段：无 AWS 的本地回放

入口：站点首页 →「打开本地回放」，对应 `portfolio/player.html`。

## 已实现

- 自制的 12 秒 H.264 教学动画：默认即可播放，无比赛录像和外部素材。
- 与动画时间轴一致的四个合成事件：回合开始、传球、三分出手、三分命中。
- 点击事件跳转并暂停，播放时自动跟随当前事件。
- 老球迷、新球迷、一起看三种说明方式。
- 选择本地视频，通过浏览器 Blob URL 播放；不上传视频、不请求 AWS API。
- 在当前时刻添加或删除人工标记，导出与导入 JSON 时间线。
- 按关键词查询当前模式下的事件名称与记录原文，附时间及来源；无匹配时明确返回没有记录。

原 `web/` 比赛版本保留。这里将回放能力迁移为独立静态模块，而不是恢复失效的云端接口。

## 数据与保存

选择本地视频时清空教学事件，绝不把教学数据套在用户视频上。导入事件必须满足版本、文件标识、视频时长及事件时间范围约束。验证失败保留已有标记；导入文本通过 `textContent` 展示，不执行 HTML。

本地视频按文件名、文件大小和时长匹配，不是内容哈希校验，不证明标记语义或帧级对应关系。导入的文本统一标注为未经独立核验的用户记录，不因 JSON 自称官方数据就采信。

视频与标记仅在当前页面会话中保留。切换视频或刷新前需导出时间线；下次选择同一视频后再导入 JSON。导出文件不包含原视频。

教学片是无声动画，使用与同一页一致的合成事件，不是模型生成或真实比赛识别结果。自选视频是否带声音取决于文件本身；格式支持取决于浏览器，建议使用 H.264 MP4。

## 验证

```bash
node scripts/qa/check_timeline.mjs
python3 scripts/qa/check_local_replay.py
```

第二条需要 Playwright 与 Chromium。浏览器检查覆盖：真实播放、跳转暂停、三种模式、查询、标记添加删除、导出回导、拒绝错误和不匹配 JSON、HTML 文本安全显示、本地视频切换、桌面/手机宽度及无外部/AWS 请求。

本地运行：`python3 -m http.server 8000 --directory portfolio`。教学片会缓冲为 Blob，避免普通预览服务器没有 Range 支持导致跳转无效。

重新生成教学片：`python3 scripts/build_teaching_video.py`，需要 FFmpeg（libx264、drawtext）；生成结果提交到 `portfolio/media/teaching.mp4`，访客与部署流程不需要 FFmpeg。
