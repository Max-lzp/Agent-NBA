# 识别：读记分牌、读号码、查名单

> 10.9 两段训练片（阿门、弗拉格）调出来的经验。代码在 `pipeline/vision/scoreboard.py`、`jersey_ocr.py`、`roster_map.py`、`pipeline/events/identity.py`、`possession.py`、`shots.py`。
> 一句话：**画面里最可信的是记分牌，尤其是进攻钟。**球员位置、球、球衣颜色都会错，记分牌上的数字几乎不会错。

## 1. 为什么记分牌是关键

视觉能告诉我们「谁离球近」，但判不准「现在哪队在进攻」：

- 球真正被检测到的帧只有 38%（阿门）/ 44%（弗拉格），其余是插值补的。
- 球衣颜色在贴身防守、重叠框上经常把人分错队。阿门片 9–12 秒，火箭持球人被颜色判成独行侠，回合直接判反。
- 不读记分牌时，进攻方判对只有 amen 40% / flagg 90%；读了记分牌以后是 100% / 98%。

记分牌上的数字是转播方给的，等于免费的真值。

## 2. 读什么、怎么读

本地 RapidOCR，不调大模型，每秒抽 3 帧，只读画面下方 25%（`STRIP_TOP = 0.75`）。识别置信度低于 0.6 的文字丢掉。

| 字段 | 怎么认 | 例子 |
| --- | --- | --- |
| 比赛钟 `clock` | 第一个 `M:SS` 格式的文字，也是定位其他字段的锚点 | `7:45` |
| 节次 `period` | `1ST/2ND/3RD/4TH/OT` | `3RD` |
| 进攻钟 `shot_clock` | 比赛钟**右侧**、离它最近、≤ 24 的数（可带一位小数） | `19`、`3.5` |
| 两个比分 `scores` | 比赛钟**左侧**、竖直距离 < 120px、离它最近的两个 2–3 位数；按先上后下、先左后右排 | `[60, 63]` |

- **客队在前**：NBA 转播记分牌左（上）是客队、右（下）是主队。每段片的客主队写在 `pipeline/vision/clips.json`（阿门 HOU @ DAL，弗拉格 DAL @ HOU）。
- 含 `TO`（暂停数）、`/`、`:` 的文字不当比分或进攻钟。
- `O` 当 `0` 读。

两段片的读数质量：

| 片段 | 读数次数 | 比赛钟 | 进攻钟 | 比分 |
| --- | --- | --- | --- | --- |
| 阿门（3RD 7:45 起，60–63） | 69 | 69 | 69 | 69 |
| 弗拉格（4TH 1:52 起，103–107） | 65 | 65 | 65 | 47 |

弗拉格片比分有 18 次没读到（转播图层遮挡），还有一次误读成 `[35, 103]`。后面的确认规则能把它挡掉。

## 3. 记分牌里的时间：三条规则

### 规则一：进攻钟往上跳 = 球权重置

进攻钟正常只会往下走。比上一次读数**多 3 秒以上**（`RESET_JUMP = 3.0`）就记一次重置（24 或 14）。

- **没有进攻钟重置，就不允许换球权。**这是修好阿门片的那条规则：持球人颜色再怎么像对方，进攻钟没重置就是同一个回合。
- 换球权的时刻取**重置时刻**，不取持球人变化的时刻（持球人变化往往晚半秒到一秒）。
- 换边的佐证有容差 `RESET_TOL_S = 1.5` 秒。

### 规则二：比分跳变要连续读到 2 次才算

`CONFIRM_READS = 2`。新比分还必须同时满足：只有一边变、变化 1–3 分、不能减少。否则视为 OCR 错字丢弃。确认后得到一条得分记录：

```json
{"t_sec": 21.021, "team": "HOU", "delta": 2, "t_reset": 19.353}
```

### 规则三：比分变化比球进晚，球进的时刻看进攻钟

转播图层更新比分有延迟。实测：

| 片段 | 进攻钟重置（球进） | 比分变化被确认 | 延迟 |
| --- | --- | --- | --- |
| 阿门（HOU +2，Capela） | 19.35 s | 21.02 s | 1.7 s |
| 弗拉格（DAL +2） | 18.02 s | 20.69 s | 2.7 s |

所以：

- 得分前 3 秒内（`RESET_LOOKBACK_S = 3.0`）最近的一次进攻钟重置 = **球进的时刻** `t_reset`。
- 出手时刻 = 球进前约 1 秒（`SHOT_TO_MADE_S = 1.0`），并且不早于持球段结束：`t_shot = max(min(持球段结束, t_made), t_made − 1.0)`。
- **得分造成的进攻钟重置不能当换边佐证**，否则弗拉格片会在 15.4 秒提前换边。得分本身就换了球权，由得分记录处理。

### 补充：比赛钟

- 比赛钟和视频时间 1:1 走（阿门 0 秒 7:45 → 22 秒 7:23），可以用来把视频时间对齐到官方逐回合数据（考试视频发布后接）。
- 第四节最后两分钟、以及每节最后，**投进后比赛钟会停**。弗拉格片 18–20 秒钟停在 1:34 不动，就是刚进球的信号。

## 4. 读号码

`jersey_ocr.py` 的 `RapidJerseyReader`：

1. 每条轨迹挑**框最高的 8 帧**（框高 < 70px 的不要，太小读不出）。
2. 裁躯干：框高 18%–62%、左右各去 12%（`team_color.torso_crop`），高度不到 160px 就放大。
3. OCR 只留 1–2 位纯数字；`0` 和 `00` 保留，其余去掉前导零。
4. 8 张投票，**第一名和第二名票数一样就弃权**，宁可没号码也不要错号码。

YOLO 号码模型（Roboflow `jersey_numbers.pt`）目前下不到权重，没用上。

## 5. 查名单：号码对了，名字就对了

比赛规定赛季是 2025-26，球队一定是火箭（HOU）和独行侠（DAL），所以存一份固定名单，号码 + 队伍直接查人。

- 名单文件：`pipeline/vision/rosters/2025-26.json`，格式见同目录 `season.schema.json`。
- `roster_map.identify(jersey, team, color, ...)` 的顺序：先看这场的出场名单；再按队伍（或球衣颜色推出的队伍）在赛季名单里找号码。
- 号码只在一队存在时，号码比颜色可信：颜色判 HOU、号码只在 DAL 有，就信号码（置信度 0.7）。
- 两队同号且分不出队：按 `minutes`、`games` 排序取上场多的，置信度降到 0.6。上场多的人出现在画面里的概率更大。
- 赛季中途转会用 `since` / `until` 限定时间段。

## 6. 一条轨迹只对应一个人

`pipeline/events/identity.py`：

- 同一个球员的多条轨迹，如果**同一时刻共存超过 1 帧**（`MAX_OVERLAP_FRAMES = 1`），只留号码投票票数多的那条。
- 没读到号码的短轨迹，如果在已知轨迹消失后 **1 秒内、220px 内**出现，并且是同一队，就拼过去（置信度 × 0.7）。
- 还是没身份的，页面写「火箭球员」/「独行侠球员」，不编名字。

## 7. 球：只信真看见的

- `analyze.py` 给球做了插值和回填，timeline 里每帧都有球是假象。`ball_raw.py` 产出 `ball_raw.json`，标出哪些帧是真检测到的球。
- **持球人只在真看见球的帧换人**；插值帧、两队贴身争抢的帧只能延续当前持球人。
- 同一人 3 秒内重新确认持球，接回原来那段，避免切碎。

## 8. 官方数据怎么帮识别

有官方逐回合时（`pipeline/enrich`，见 `pipeline/enrich/README.md`）：

- **认比赛**：记分牌每次读数（节次 + 比赛钟 + 比分）对各场官方比分，训练片 81% / 72% 对上，其他场 0%。
- **投篮人、助攻**：进球按进球后的比分精确对上官方记录；投篮人的名字回填到同一条轨迹上没名字的引用，助攻者回填到传给投篮人的那一传。号码认出的人不被覆盖，打架时记 `track_conflicts`。
- **场上 10 人**：逐回合里的换人推出片段开始和结束时在场的人，写进 `roster.json` 的 `on_court`。识别时号码不在场上就不给名字。
- **出场名单按号码比**：官方短名（Thompson）和赛季名单的叫法（Amen / Klay）不一样，按名字比会失效。

## 9. 左右

- 一律按**投篮人面向篮筐时的左右**，和官方区域名 Left Corner 3 一致。
- 官方坐标 `xLegacy` 为负 = 左：四场 259 次带左右区域名的投篮全部如此。
- CDN 逐回合的 `side` 字段**不是**投篮人左右，是电视画面里的左 / 右半场（随 `x < 50` 走），存成 `court_half`。

## 10. 已知短板与考试视频上要复核的

- 阈值只在两段片上调过，有过拟合风险。考试视频先跑一条命令，看终端的记分牌读全比例和白衣投票。
- 持球人的号码常读不到（弗拉格片多数传球人没名字）；有官方数据时投篮人、助攻者、被认出的轨迹能补上，其余仍是「独行侠球员」。
- 记分牌位置假设在画面下方 25%，找不到时整帧找；客主队以记分牌读到的队名为准。
- 比赛钟最后一分钟（`SS.s`）有单测，训练片里没出现过。
- 掩护识别、英尺距离（单应矩阵）还没做。

## 命令

```bash
cd team-repo
python3 -m pipeline.run_clip --video "../官方资料/<视频>.mp4" --clip exam      # 一条命令，见 docs/exam-day.md
pipeline/vision/.venv/bin/python pipeline/vision/scoreboard.py --clip all   # 只跑记分牌
python3 -m pipeline.events.evaluate                                         # 带记分牌评估
python3 -m pipeline.events.evaluate --no-scoreboard                         # 对照：不读记分牌
```

`evaluate --dump pipeline/events/out` 会用不带官方补全的清单覆盖 `out/`，之后要再跑一次 `run_clip --skip-vision`。
