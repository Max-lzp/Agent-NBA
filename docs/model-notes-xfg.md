# xFG 偏差分解：可解释的描述统计 MVP

## 公式与画面口径

对同一赛季、同一比赛类型、同一出手口径的球员，记平均预期命中率为 q（AVGSHOTQUALITY），实际减预期命中率为 e（FGPCTABOVEEXPECTED），可比基准命中率为 b。

`实际命中率 - b = (q - b) + e`

- 出手质量贡献：`100 × (q - b)`，单位为百分点，也等于每 100 次出手相对基准多/少的预期命中次数。
- 执行残差：`100 × e`，包含技术、运气、样本波动和模型误差，不能单独归因于球员能力。
- 总偏差：`100 × (q + e - b)`，两项相加必须守恒。

评委解释：“把命中率的高低拆成两件事：获得了多好的出手机会，以及实际命中比模型预期多或少多少。”

输出 JSON 的 `players[].overlay.text` 可直接交给只读呈现/解说旁路；横轴为质量贡献、纵轴为执行残差的 PNG 用于评审说明。未接入前端，不修改主链路。

## 数据与限制

使用真实 `data/deep/*.csv`，字段可通过 CLI 显式映射。运行时必须声明 `fraction`（0–1）或 `percent`（0–100），不猜单位。必须从来源字段字典核实 AVGSHOTQUALITY 是**预期命中概率**，FGPCTABOVEEXPECTED 是**命中率差值**，且二者使用相同的出手权重、赛季和比赛类型；若不是此定义，不能运行本公式。原始质量指数、相对提升比率、球员引力都不能直接替代这两个字段。

基准 b 必须显式提供来源，不默认写一个“联盟均值”。没有出手次数时不能用不加权的球员均值冒充联盟命中率。赛季汇总只能描述赛季，不能移植为某次出手的 xFG。高低排名没有校正出手次数，不是显著性或能力排行榜。本 MVP 不提供显著性、贝叶斯后验或胜率因果结论。

混合两分和三分时，命中次数差不是得分差；球员汇总输出因此只写百分点/命中次数，不写“净赚多少分”。

## 增强回放候选（需真实事件数据）

可选 `--replay-input` 接收已核验且对齐视频的事件 CSV：

`event_id,game_id,player,period,clock,video_time_s,leverage,shot_quality,made,shot_value,source`

`made` 为 0/1，`shot_value` 为 2/3，`shot_quality` 单位与主输入一致。`leverage` 必须是已定义的非负**事件级关键度**，通过 `--leverage-definition` 留痕。不能用球员赛季 TOT_LVG 给每次出手赋值，也不能称它为 WPA；WPA 需要同一口径的回合前后胜率，本实现未估算胜率。

按关键度选最高的最多 5 次出手，输出 `预期得分 = shot_value × shot_quality` 和 `实际-预期 = shot_value × (made-shot_quality)`。这是单次实现结果的残差，不代表技能或决策质量。若源数据不足 3 条，保留实际数量，不补造。候选片段建议取出手前 4 秒、后 3 秒；结束点需要人工核查视频边界，JSON 会标记。候选的比赛时钟和视频偏移必须经过比分牌或官方时间锚点校验，不能把比赛时钟直接当视频秒数。

## 当前交付状态

已直接从 NBA 官方主站页面确认接口并拉取真实数据：data/deep 内有 125 人出手难度、234 人引力、234 人 Leverage 及两名训练球员共 41 次出手的 CSV、原始响应与哈希清单。官方 glossary 确认 AVGSHOTQUALITY 和 FGPCTABOVEEXPECTED 的定义；125 行均满足 `AVGSHOTQUALITY + FGPCTABOVEEXPECTED = FGPCT`。

已生成 `pipeline/vision/models/results/xfg_deviation_output.json` 与 PNG，覆盖返回样本中的 HOU 5 人、DAL 3 人。基准是 125 人官方跟踪 FGA 加权 xFG，约 46.5813%；只是该合格样本的预期基准，不能称作联盟实际命中率。原始 xFG 四舍五入会影响汇总精度。模型保留球员 ID、球队、跟踪出手次数及来源。

可上画面的真实结论：“杜兰特的跟踪出手预期命中率为 43.3%，实际 52.0%，比预期高 8.7 个百分点；阿门的预期为 58.7%，实际 53.4%，比预期低 5.3 个百分点。”这是赛季描述统计，不是单次出手能力或运气的因果结论。不能把赛季数值直接贴到单球上当单球 xFG。

`shot_sequence_output.json` 包含 41 条真实单球 xFG/预期得分叠加信息及 5 个按绝对得分残差挑选的候选，留存官方视频 URL、eventNum、比赛时钟。这 5 个是“出手结果偏差大”的候选，**不是已核验的高 Leverage 回合**。源 shotList 没有事件级 Leverage；已尝试官方 winprobabilitypbp 接口，两场均返回 HTTP 500，未得到可用 WPA。高关键度排序和上传训练视频内的偏移仍待接入；不伪造赢球概率或时间锚点。

复现程序 `run_official_model.py` 首先核对原始响应和 CSV 的 SHA-256，任何变动会拒绝继续，之后按明确的样本基准生成 JSON 与图表。合成数据仅用于测试，不作为正式输出。
