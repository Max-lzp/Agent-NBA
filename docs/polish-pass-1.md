# 第一轮投递版精修

本轮只处理首屏和一个主回合，保留 Deep Court 的原字体、黑橙主题与弗拉格真实比赛成片。

## 改动

- 默认新球迷模式，取消离线展示的强制模式弹层。
- 首屏精简为标题、短说明、模式与播放器；项目长文、术语、完整事件、球员列表和完整数据改为按需展开。
- 视频旁提供“发生什么、为什么值得看、数据说明什么”三层解释。新球迷、进阶数据和一起看模式使用不同内容。
- 以三个明确节点组织主回合：回合开始、看出手、定格复盘。点击会跳转并暂停。
- 完整 11 个事件、热区图、原始数据、球员头像、引导式查询和官方教学入口保留。
- 为首帧加载准备同一比赛成片的海报图；公网使用原生视频和 Range 分段加载，本地普通服务器仍保留缓冲回退。
- 当前解释是基于已有记录的编辑内容，没有新宣称自动战术识别或实时模型问答。

本地 Chromium，默认页面，手机选择/默认新球迷模式，未滚动。数值是布局测量，不是用户转化或线上性能指标。

## 验证

视觉基线：[桌面截图](design-baseline/desktop.png) · [手机截图](design-baseline/mobile.png)。后续调整先与这版比较，避免再次改变作品识别度。

`python3 scripts/qa/check_archive_replay.py` 已覆盖：默认模式/无弹层、手机首屏、三个观看节点、三种不同解释、原有事件跳转、数据/头像展开、归档解释、无重复定格、无资源缺失和无 AWS 请求。另用本地 Range 服务器模拟公开域名，验证原生播放路径可以跳转。

当前公开媒体源实际返回 HTTP 206 与 Content-Range，确认支持 Range；不因此声称所有设备、网络都秒开。
